# Homebrew Tap for RazerMon

Install the latest Apple silicon release of [RazerMon](https://github.com/ab4317/RazerMon):

```sh
brew install --cask ab4317/tap/razermon
```

RazerMon requires macOS 13 or later and Input Monitoring permission.

The app is independently distributed and is not notarized by Apple. If macOS blocks the first launch, Control-click RazerMon in Applications, choose **Open**, then confirm **Open**.

Uninstall with:

```sh
brew uninstall --cask razermon
```
